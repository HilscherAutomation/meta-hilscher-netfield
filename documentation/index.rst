The netFIELD-OS documentation
=============================

Introduction
------------

netFIELD OS
 * is a hardened minimalistic linux based operating system
 * comes with pre-installed docker required to install add on software
 * comes with services to manage a device from netfield.io cloud
 * comes with an additional docker-instance managed by netfield.io
 * *optionally* provides fieldbus / network analyzing devices, sold by `Hilscher Gesellschaft für Systemautomation mbH <https://www.hilscher.com/>`_
